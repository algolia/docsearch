# Algolia DocSearch for Kiro

Search public developer documentation from Kiro. The power connects to Algolia DocSearch MCP and includes a skill for retrieving and citing relevant excerpts. The connection requires no Algolia account or API key.

## Install from a folder

1. Open the **Powers** panel in Kiro and select **Add Custom Power**.
2. Select **Import power from a folder** and choose this directory.
3. Select **Install**.

Ask Kiro to use DocSearch to find how Vite exposes `VITE_` environment variables through `import.meta.env`. The power should activate and return source links for the documentation it uses.
