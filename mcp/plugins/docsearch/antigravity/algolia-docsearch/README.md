# Algolia DocSearch for Antigravity

Search public developer documentation from Antigravity. Algolia DocSearch returns excerpts and source links for libraries, frameworks, SDKs, APIs, CLI tools, and cloud services. The MCP server requires no Algolia account or API key.

The plugin includes a skill that tells Antigravity when to look up documentation and how to cite the results. It uses `algolia_docsearch_search_docs` for ordinary lookups and can resolve and query specific documentation sets when needed.

## Try it

Ask Antigravity to use Algolia DocSearch to find how Vite exposes `VITE_` environment variables through `import.meta.env`.
