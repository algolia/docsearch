The `@docsearch/starlight-adapter` package connects an Astro Starlight site to Algolia DocSearch v5. It replaces the default Pagefind search with keyword search backed by your Algolia indices.

## Guides

- [Getting Started](./guides/getting-started/): requirements, installation, and plugin registration.
- [Search Configuration](./guides/search-configuration/): indices, search parameters, and text overrides.
- [Adapter Reference](./reference/example/): supported options and integration behavior.

## Playground Index

This playground searches the public DocSearch documentation index. Results link to hosted DocSearch documentation, not the local pages you are reading. The adapter does not crawl or automatically index this site.
