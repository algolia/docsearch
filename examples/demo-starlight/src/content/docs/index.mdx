title: DocSearch + Starlight
description: Algolia DocSearch v5 keyword search and Ask AI for Astro Starlight.
---

The `@docsearch/starlight-adapter` package connects an Astro Starlight site to Algolia DocSearch v5. It replaces the default Pagefind search with keyword search backed by your Algolia indices, and can add Ask AI in the search modal or a side panel.

## Guides

- [Getting Started](./guides/getting-started/): requirements, installation, and plugin registration.
- [Search Configuration](./guides/search-configuration/): indices, search parameters, and text overrides.
- [Ask AI](./guides/ask-ai/): Agent Studio agents and the Ask AI side panel.
- [Adapter Reference](./reference/example/): supported options and integration behavior.

## Playground Index

This playground searches the public DocSearch documentation index and uses a public Ask AI agent. Results link to hosted DocSearch documentation, not the local pages you are reading. The adapter does not crawl or automatically index this site.
